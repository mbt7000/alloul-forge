# Attribution

The notes in this sample vault were generated by `tools/graphify.py` from the
**official Claude Code documentation** published by Anthropic at
https://code.claude.com/docs (index: https://code.claude.com/docs/llms.txt).

The documentation content belongs to Anthropic. This directory contains a
small 12-page sample committed for demonstration purposes only — each note
carries its `source:` URL in its frontmatter. To build the full, up-to-date
vault yourself (165+ pages), run:

```bash
python3 tools/graphify.py obsidian https://code.claude.com/docs/llms.txt --vault ../claude-code-vault --allow-network
```

Then open the folder in Obsidian and check the graph view.
