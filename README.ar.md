# علّول فورج — Alloul Forge

**35 مهارة قابلة للنقل بين Claude وChatGPT/Codex وCopilot**، مع تثبيت محلي، وتصدير مناسب لكل منصة، وأداة لتنظيم مستندات Markdown في عقل معرفي.

[English](README.md) · [التوافق ومصادره](docs/COMPATIBILITY.md) · [الأمان وحدوده](SECURITY.md)

المشروع يضيف إجراءات عمل للبحث والبرمجة والمراجعة وتنظيم المعرفة وتطوير المهارات. لا يدرّب أوزان النموذج، ولا يمنح صلاحيات، ولا يربط حسابات الشركة تلقائيًا. الأدوات المتاحة فعليًا تحددها المنصة وإعدادات المؤسسة.

## البداية

يتطلب Python 3.11 أو أحدث. أدوات المشروع لا تحتاج حزم Python خارجية أو مفاتيح API، ولا ترسل بيانات تحليل استخدام أو تطلب تشغيل نموذج. راجع نسخة محددة من الكود قبل تثبيتها.

```bash
python3 tools/skill_lint.py
python3 tools/security_scan.py
python3 -m unittest discover -s tests -v
python3 tools/forge.py list
```

## التثبيت للمنصات البرمجية

```bash
python3 tools/forge.py install --target codex --destination ../my-project --skill debug-protocol --dry-run
python3 tools/forge.py install --target codex --destination ../my-project --skill debug-protocol
python3 tools/forge.py install --target claude --destination ../my-project
python3 tools/forge.py install --target copilot --destination ../my-project
python3 tools/forge.py install --target all --destination ../my-project
```

- Codex: يكتب في `.agents/skills`.
- Claude Code: يكتب في `.claude/skills`.
- GitHub Copilot: يكتب في `.github/skills`.
- `all`: يجهّز المسارات الثلاثة، و`universal` يجهّز `.agents/skills` للمنصات التي تدعمه.
- استخدم `--skill` لاختيار المهارات بدل تركيبها كلها. على Windows يمكن استخدام `python` بدل `python3`.

المثبّت ينقل موارد المهارة اللازمة معها. لا يشغّل مواردها، ولا يعدّل إعدادات الصلاحيات، ولا ينشئ اتصالات أو مهام مجدولة. الملفات الموجودة غير المملوكة له، أو التي عدّلها المستخدم، تؤدي إلى تعارض واضح بدل الاستبدال الصامت. تحديث الملفات المولّدة المملوكة له ينشئ نسخة احتياطية. المهارات التي لم تخترها في تشغيل لاحق لا تُحذف تلقائيًا.

## ChatGPT وCopilot Studio

```bash
python3 tools/forge.py export --target chatgpt --output ../forge-chatgpt
python3 tools/forge.py verify ../forge-chatgpt
python3 tools/forge.py export --target copilot-studio --output ../forge-studio --skill work-hub --skill plan-builder
python3 tools/forge.py export --target portable --output ../forge-portable
```

تصدير ChatGPT ينتج مصدر إضافة مهارات فقط، بصيغة `.codex-plugin/plugin.json`، دون خادم MCP أو اتصالات أو مفاتيح أو hooks. تثبيتها أو تقديمها للدليل يتم بالطريقة التي تدعمها المنصة؛ الأمر لا ينشرها ولا يثبتها في حسابك، ولا يضمن قبولها.

تصدير Copilot Studio ينتج ملفات مهارات وتعليمات منفصلة ومتحكمًا أقل من 8,000 حرف. استخدم واجهة Skills إذا كان نوع الأجنت يدعمها، أو إجراءات مختارة في واجهة التعليمات وفق حدود حسابك. رفع الملفات لا ينشئ أدوات تنفيذ أو صلاحيات أو ربطًا بـTeams وOneNote. هذه إعدادات مستقلة داخل المؤسسة.

المنصات الأخرى تستطيع استخدام التصدير العام إذا كانت تدعم Agent Skills أو التعليمات المرفقة؛ لا يوجد ادعاء بأن كل خدمة ذكاء اصطناعي تشغّل المهارات محليًا بالطريقة نفسها.

## محتوى المهارات

| المجموعة | الوظيفة |
|---|---|
| استقبال المهام | فهم الطلب، اختيار الإجراء، والعمل ضمن حدود واضحة |
| التنسيق | تقسيم المشكلة، مراجعة النتائج، والتحقق بالأدلة |
| الهندسة | تصحيح الأخطاء والاختبارات والأداء والتوثيق وتصميم API |
| البحث والتحليل | مصادر موثقة، مقارنة الأدلة، وتوضيح عدم اليقين |
| تطوير المهارات | استخراج إجراءات متكررة، اختبارها، وضبط إعداد المساعد |
| المعرفة والتعلّم | تنظيم العمل والقرارات والأهداف وسجل التعلم |

تحولت مهارة `claude-tuner` إلى `assistant-tuner`. لا يحذف المثبّت النسخة القديمة تلقائيًا؛ راجع إزالتها عند الانتقال. الملف الشخصي الافتراضي `~/.alloul-forge/profile.md` خارج المستودعات، ولا ينشئه المثبّت.

تتضمن المهارات قواعد تحترم صلاحيات المنصة، وتتعامل مع المستندات ونتائج الأدوات كبيانات غير موثوقة، وتمنع نسخ الأسرار للمهارات المشتركة. عدم توفر الأدلة يعني «غير قابل للتحقق». التجارب المتتابعة داخل سياق واحد لا تُعرض كتقييم A/B مستقل. تقييم `debug-protocol` التاريخي مثال مسجّل، وليس إثباتًا لأداء جميع المهارات أو جميع المزوّدين.

## تنظيم المعرفة مع حماية الملفات

```bash
python3 tools/graphify.py obsidian ./my-docs --vault ../my-vault --dry-run
python3 tools/graphify.py obsidian ./my-docs --vault ../my-vault
```

المجلد المحلي يعمل دون شبكة. لتنزيل فهرس Markdown موثوق:

```bash
python3 tools/graphify.py obsidian https://code.claude.com/docs/llms.txt --vault ../docs-vault --allow-network
```

الشبكة متوقفة افتراضيًا. عند تفعيلها يُسمح بمضيف الفهرس فقط، ويمكن إضافة مضيف موثوق عبر `--allow-host HOST`. تُحجب العناوين الخاصة والمحجوزة و`file://` والروابط التي تحتوي بيانات دخول والتحويلات غير الآمنة. لا تستخدم الأداة إعدادات proxy من البيئة. HTTP غير المشفر يحتاج `--allow-http` منفصلًا.

الحدود الافتراضية: 200 صفحة، و2 MiB للصفحة، و32 MiB للمحتوى الكلي، و300 طلب، ومهلة socket قدرها 10 ثوانٍ. `--include` يرشح المصادر، و`--limit` يغير سقف الصفحات إلى حد أقصى 2,000. تجاوز الحد يوقف التشغيل بوضوح. الأداة تستورد Markdown والنصوص، ولا تزحف أي موقع HTML عشوائيًا.

ملف `.forge-vault.json` يسجل بصمات الملفات المولّدة. الملفات البشرية أو التعديلات عليها لا تُستبدل؛ التعارض يوقف التجهيز. فشل التنزيل يحافظ على المحتوى السابق، وتحديث الملفات المولّدة ينشئ نسخًا في `.forge-backups/`. الكتابة آمنة لكل ملف على حدة، وليست معاملة واحدة لكل المجلد؛ راجع حدود التعافي في وثيقة الأمان.

للانتقال من عقل قديم غير مُدار، أنشئ مجلدًا جديدًا ثم راجع النقل. لا تكتب فوق المجلد القديم. المحتوى المستورد قد يتضمن معلومات خاصة أو تعليمات حقن؛ راجعه قبل مشاركته أو إعطائه للأجنت.

## حدود فحص الأمان

فحص الأنماط والاختبارات الآلية يساعدان على كشف مخاطر محددة. لا يمثلان شهادة بالخلو المطلق من الأكواد الخبيثة أو الثغرات. التحقق بالبصمات يكشف تغير الملفات مقارنة بالسجل المحلي؛ لا يثبت هوية ناشرها. الاختبارات محلية دون اتصالات بالنماذج، واختبار القبول الفعلي داخل حسابات المنصات خطوة مستقلة.

ترخيص MIT لكود المشروع. عيّنة مستندات الطرف الثالث تحت [إسنادها الخاص](examples/claude-code-vault-sample/ATTRIBUTION.md).
